Lab guide 11

Integration and Break/Fix Week

No new material. Combine everything into realistic, multi-step problems and time yourself.

10-12 hours Weeks 1-10 complete on both machines
Before you start
  • Snapshot both machines now, before you start breaking things
  • Have a timer ready — a phone timer is fine

1. Drill A — storage + networking (45 minutes)

Cross-domain, timed. Don't look at earlier weeks unless you get stuck for more than 10 minutes.

Set it up
echo '=== Task: extend the lfcs-lv logical volume by 1G, format the extra space is not needed — just grow the filesystem in place, then export the mount point over NFS to the other lab machine and mount it there persistently. ==='

2. Drill B — users + security (45 minutes)

Combine an access-control task with a mandatory-access-control task.

Set it up
echo '=== Task: create a new user restricted to a single directory via ACLs, then confirm SELinux/AppArmor does not silently block that access once a service tries to read a file the user created. ==='

3. Drill C — scheduling + services (45 minutes)

A timer that manages a service, with a deliberate ordering dependency.

Set it up
echo '=== Task: write a systemd timer that restarts a service every 10 minutes only if a specific log file has grown in size since the last check. ==='

4. Full rebuild from a clean snapshot

Prove you can stand the whole two-machine topology back up from nothing, on both distros.

Roll back and rebuild
echo 'Restore both VMs to their pre-Week-1 snapshot in your hypervisor UI.'
echo 'Reinstall the base OS updates, recreate lfcsuser, rejoin the two machines over SSH, and re-run the Week 7 LVM build end to end — this time without this guide open.'

5. Break five things blind

One per domain. Don't write down what you did. Then diagnose and fix each cold, exactly like exam day.

The five, pick your own specific break for each
echo '1. Essential Commands — corrupt a systemd unit file syntax error'
echo '2. Users and Groups — misconfigure a sudoers rule'
echo '3. Operations Deployment — mask a critical timer or service'
echo '4. Storage — put a bad UUID in fstab'
echo '5. Networking — block a port the load balancer needs'

Verify your work

Run these before you consider the lab finished.

  1. All three timed drills completed within their time box, or you know exactly which step ran over and why
  2. Full topology rebuild completed without this guide open
  3. All five blind breaks diagnosed and fixed, and you wrote down the fix afterward for your break/fix log
Break it, then fix it

Break:

# This week IS the break/fix drill — see steps 4 and 5 above.

What you'll see: Whatever you chose to break, cold, without a script telling you what changed.

Fix:

# Diagnose from first principles: systemctl status, journalctl, mount -a, ss, and the audit log are your five best friends.

Why it matters: By Week 11 the specific commands matter less than your diagnostic process. If you can walk into a broken system with no hints and find the fault in under 10 minutes, you're ready for Week 12.
